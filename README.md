# MESO_ARMS_2024

## Overview

This repository contains the full analytical workflow supporting the manuscript “Beta diversity and rarity assessment of sessile cryptobenthic communities across depth and islands can inform coral reef conservation”, accepted for publication in Diversity and Distributions, an open access, international, biodiversity journal devoted to the advancement of conservation biogeography.


The repository ensures reproducibility, transparency, and traceability of all analyses and figures presented in the manuscript. All results, tables, and graphical outputs are generated programmatically from raw and processed data using a fully specified R environment and a pipeline-based workflow.

## Repository structure

```
MESO_ARMS_2024/

```

## Reproducible workflow

### {targets} pipeline

All analyses are orchestrated using the {targets} package.

The full analytical workflow (data processing, statistical analyses, and figure generation) is defined in `_targets.R`.

Running the complete targets network reproduces all results and outputs used in the manuscript. Intermediate objects are cached automatically to ensure efficiency and reproducibility.

To run the full pipeline:

```r
targets::tar_make()
```

All outputs produced by the pipeline are written to the `outputs/` directory.

## R environment and dependency management

### {renv}

This project uses {renv} to ensure a stable and reproducible R environment. All package versions are locked in `renv.lock`. The `renv/` directory contains the infrastructure required to restore the environment.

To restore the exact package versions used for the analysis:

```r
renv::restore()
```

### Package version tracking

In addition to `renv.lock`, the file `package_versions.csv` provides a human-readable snapshot of all R packages and versions used in the project at the time of analysis.

## Custom functions

All user-defined functions used in the analyses are stored in the `R/` directory. These functions are sourced automatically by the {targets} pipeline. They include utilities for:

- Data processing
- Diversity metrics
- Rarity indices
- Mapping
- Figure generation

## Outputs

The `outputs/` directory contains all derived results generated by the pipeline, including:

- Statistical summaries
- Figures and maps
- Tables used directly in the manuscript or supplementary materials

No manual editing of outputs is required or expected.
